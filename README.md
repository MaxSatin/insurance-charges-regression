## Прогнозирование медицинских расходов insurance-charges-regression

Описание: анализ факторов, влияющих на медицинские расходы, на основе регрессионных моделей. 

## Задачи:

- Построить модель, оценивающую медицинские расходы на основе характеристик клиента, позволяющую бизнесу в перспективе корректировать стоимость страховки для указанных категорий клиентов.
- Сравнить алгоритмы регрессии и выявить наиболее значимые признаки, влияющие на прогнозные результаты модели. 

## Практическое применение

Проект может быть основой анализа структуры медицинских расходов и оценки ошибок прогнозирования в разных сегментах клиентов. 

## Данные

Использован открытый датасет Medical Insurance Cost, содержащий 1 338 наблюдений, 6 исходных признаков и 1 зависимую переменную "charges" (стоимость медицинских услуг, $).
Список признаков: 
- age - возраст клиента;
- sex - пол клиента;
- bmi - индекс массы тела клиента;
- children - количество детей;
- smoker - статус курения;
- region - регион пребывания;
- charges - стоимость медицинских услуг (зависимая переменная).

В данных не обнаружено пропусков.

## Ход исследования:

1. EDA: изучены структура набора данных, описательные статистики и распределение медицинских расходов, построены визуализации.
2. Преобразована целевая переменная при помощи log(charges) для сокращения правосторонней асимметрии распределения (коэффициент асимметрии: до 1,516 после −0,09).
3. Предобработаны признаки: категориальные переменные преобразованы с помощью one-hot encoding (drop_first=True). Для линейных моделей использован StandardScaler с обучением на тренировочной выборке.
4. Разделены данные: 80% на обучение (1 070 наблюдений) и 20% на тест (268 наблюдений), random_state=42.
5. Построены модели: обучены LinearRegression, Ridge(alpha=1.0) и RandomForestRegressor(n_estimators=100, random_state=42).
6. Оценены результаты: рассчитаны R², MAE и RMSE. Отдельно рассмотрены ошибки для 10% наблюдений с наибольшими фактическими расходами с целью сравнения точности результатов моделей линейной регрессии и Случайного Леса. Исследована важность признаков Random Forest.

## Результаты:

Результаты на отложенной тестовой выборке:

R² вычислен для логарифмированной целевой переменной.

Модель: Linear Regression - R² = 0,8047, МАЕ = 3 888,77$, RMSE = 7 815,31$
Модель: Ridge - R² = 0,8047, MAE = 3 885,51$, RMSE = 7 800,36$
Модель: Random Forest - R² = 0,8456 MAE = 2 086,91$, RMSE = 4 364,20$

Для MAE и RMSE прогнозы и фактические значения предварительно преобразованы обратно в доллары с помощью exp(). Поэтому эти метрики измеряются на разных шкалах.

Random Forest показал наименьшие MAE и RMSE среди трёх проверенных моделей.

## Ошибки для наиболее дорогих случаев:

Для 10% тестовых наблюдений с наибольшими фактическими расходами были получены следующие результаты:

- Linear Regression: MAE = 9 474$;
- Random Forest: MAE = 2 956$.

RandomForest точнее линейной модели в 3,2 раза на дорогих клиентах. Это критично для бизнеса: именно эти клиенты создают основные затраты. 
Линейная модель скрывает ошибку и выдает менее точные значения на хвосте распределения.

## Важность признаков:

Согласно встроенной оценке feature_importances у Random Forest, наибольшие значения получили:

smoker_yes - 0,4368;
age - 0,3805;
bmi - 0,1053;

Курение и возраст дают 82% предсказательной силы.

Стоит отметить, что показатели отражают модельную важность, а не доказательство причинно-следственного влияния признаков на медицинские расходы.

### Дополнительная кросс-валидация:

В ноутбуке выполнена 5-fold кросс-валидация Random Forest: средний R² = 0,8056 ± 0,0625 (стандартное отклонение), в логарифмической шкале.
